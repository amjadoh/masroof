# Masroof 2 Beta

The lab now contains only the independent BankEngine, Finance Core, Beta app, isolated upgrade test host and optional offline learning tools. Open Beta through Settings → App → About → Developer settings → Masroof 2.

The copied legacy parser, old Parsing Lab app, comparison adapters, old-engine tests and benchmark reports have been removed under explicit user authorization. Existing Beta databases, labels and audit history are preserved; historical archive columns remain inert for lossless compatibility, never as interpretation or financial authority. Production parsing, financial code and data are unchanged.

Use `:lab:bank-engine:test`, `:lab:finance-core:test`, `:lab:beta:testDebugUnitTest` and the existing latest-stable Android native/lifecycle CI checks. Financial approval uses one versioned current interpretation and explicit user confirmation. Partial, unsafe, OTP and unexecuted records remain review-only.

All 42 fixture files from the removed parser module were byte-identical to the retained canonical `app/src/test/resources/testdata/bank_aljazira` corpus. Their only copies under the removed module were redundant; canonical inputs and expectations were not edited. Human learning labels and original Beta messages remain in Beta storage. M9 and production migration/release remain out of scope.
